Capability Discovery

Discover provider capabilities via FHIR CapabilityStatement. The provider declares supported priority areas via instantiates and advertises Document Access Provider and/or Resource Access Provider capabilities.

sequenceDiagram participant C as Consumer participant P as Provider C->>P: GET /metadata P-->>C: CapabilityStatement Note over C: Inspects instantiates
for priority areas
(EPS, MPD, Lab, etc.)

Patient Match (PDQm/PIXm)

                
Patient identification using IHE PDQm/PIXm. Identifier-based search is required. Demographics query (ITI-78) and $match operation (ITI-119) are optional.

                
                

                    sequenceDiagram
                        participant C as Consumer
                        participant P as Provider
                        C->>P: GET /Patient?identifier=system|value
                        P-->>C: Bundle (Patient resources)
                        Note over C: Uses Patient.id
for subsequent queries

Document Exchange (MHD)

                
Document exchange using IHE MHD transactions. ITI-67: Find Document References. ITI-68: Retrieve Document.

                
                

                    sequenceDiagram
                        participant C as Document Consumer
                        participant P as Document Access Provider
                        C->>P: GET /DocumentReference?patient=... (ITI-67)
                        P-->>C: Bundle (DocumentReferences)
                        C->>P: GET /Binary/{id} (ITI-68)
                        P-->>C: Document payload

Resource Access (QEDm)

                
FHIR resource query using IHE QEDm PCC-44. All queries must be patient-scoped. Read/search only (no create/update/delete).

                
                

                    sequenceDiagram
                        participant C as Resource Consumer
                        participant P as Resource Access Provider
                        C->>P: GET /Condition?patient=... (PCC-44)
                        C->>P: GET /Observation?patient=... (PCC-44)
                        C->>P: GET /AllergyIntolerance?patient=... (PCC-44)
                        P-->>C: Bundles (Resources)
